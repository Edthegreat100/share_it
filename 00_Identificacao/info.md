## Resumo curto
Share IT é uma aplicação móvel, feita em Flutter, que permite alugar por poucos dias aparelhos eletrónicos de outras pessoas, como consolas, televisões, iPads, câmaras e projetores. Quem tem um aparelho parado ganha algum dinheiro; quem precisa dele só por um fim de semana paga apenas esses dias. Os utilizadores publicam anúncios com fotografias e datas livres, procuram aparelhos perto de si num mapa e reservam através de um calendário. A entrega e a devolução são confirmadas com QR Code, ficando registado o estado do aparelho. O sistema usa um servidor Node.js com API REST, uma base de dados MySQL e o método de Monte Carlo para sugerir um preço por dia.
